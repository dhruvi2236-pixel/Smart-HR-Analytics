# Smart HR Analytics & Employee Attrition Prediction System

## Project Overview

Smart HR Analytics & Employee Attrition Prediction System is a Python-based data analytics project developed to analyze employee data and identify patterns related to employee resignation.

The project applies data preprocessing, statistical analysis, probability, sampling, hypothesis testing, data visualization and machine learning to HR data.

It also demonstrates CRUD operations, web scraping and exception handling as part of the Python for Data Science concepts.

## Objectives

- Analyze employee information and HR-related factors.
- Identify patterns associated with employee resignation.
- Perform statistical and probability analysis.
- Apply sampling and hypothesis testing.
- Visualize important HR insights.
- Build a machine learning model for employee resignation prediction.
- Demonstrate CRUD operations with permanent data storage.
- Extract HR-related information using web scraping.
- Demonstrate exception handling for common runtime errors.
- Provide an interactive Streamlit dashboard.

### CRUD Operations

CRUD stands for:

- Create
- Read
- Update
- Delete

CRUD records are stored separately in:
